# 돛단배 — 안전·심사 보강 후보 (상세)

> 돛단배는 **익명 사용자끼리 편지를 주고받고, 마음이 통하면 익명 1:1 채팅**을 하는 앱이에요.
> 이 구조는 앱인토스의 **소셜·채팅 서비스 주의사항**(청소년 보호·개인정보·안전관리·불법행위 방지)에
> 정확히 해당돼요. 아래는 출시 심사 통과와 사용자 안전을 위해 보강하면 좋은 항목들을, 우선순위와 함께 정리한 거예요.

이미 완료된 항목: ✅ 신고/차단 + 신고 알림 메일 · ✅ 금칙어(불법광고) 차단 · ✅ 첫 채팅 안전 고지 1회 · ✅ 반복 위반 영구밴(3회) · ✅ 차단 양방향 수신자 제외.

---

## P0 — 심사 직결 (출시 전 권장)

### 1. 미성년자(청소년) 보호 정책 — ✅ 플랫폼이 이미 처리 (인앱 구현 불필요)
- **핵심**: 앱인토스 공식 콘솔 문서에 **"현재 앱인토스는 만 19세 이상 고객에게만 제공되고 있어요."** 라고 명시돼 있어요. 즉 **플랫폼 자체가 만 19세 이상 전용**이라, 미성년자는 미니앱에 **진입 자체가 불가**해요.
- **결론**: 인앱 연령 게이트(가입/채팅 차단)를 **따로 만들 필요가 없어요.** 둘러보기(게스트) 경로도 토스 앱(=19+ 전용)을 통해서만 진입하므로 동일하게 성인만 들어와요.
- **남는 할 일(가벼움)**:
  - 콘솔 미니앱 등록 시 **사용 연령을 19세 이상/성인 대상으로 설정**(문서상 입력 항목으로 존재). 스토어 노출·표기 일관성 확보.
  - 약관/소개에 "만 19세 이상 대상" 명시.
- **주의(낮은 리스크)**: 문구가 "**현재**"라, 앱인토스가 향후 더 낮은 연령대로 확대되면 그때 재검토 필요. 단기 리스크는 낮아요.
- **노력**: 거의 없음(콘솔 설정 + 표기).

### 2. 커뮤니티 가이드·금지행위 고지 + 동의
- **왜**: 비게임·소셜 심사에서 흔히 보는 항목. "불법광고·성적 콘텐츠·괴롭힘·사칭 금지" 등 운영 기준을 사용자가 인지·동의했다는 증빙.
- **구현**: 온보딩에 커뮤니티 가이드 1회 고지(필요 시 동의 체크). 신고 사유와 일관되게.
- **노력**: 소.

## P1 — 안전·신뢰 강화

### 3. 개인정보·외부유인 자동 경고 (전화번호·계좌·SNS ID)
- **왜**: 채팅에서 전화번호/계좌/카톡ID 교환은 **사기·스토킹·외부 플랫폼 유인**의 통로예요. 익명성 보호와도 직결되고, 앱인토스 "외부 링크·자사앱 유도 제한" 정책과도 맞닿아요.
- **구현**: 작성/전송 시 전화번호·계좌번호·SNS 아이디 **패턴 감지 → soft 경고**("개인정보를 알려주면 위험할 수 있어요"). 강한 버전은 표시 시 마스킹.
- **노력**: 중. **주의**: 과한 마스킹은 UX 해침 → 경고 우선.

### 4. 위기 키워드 소프트 대응 (자해·자살 등)
- **왜**: 익명 고민·감정 편지 특성상 위기 신호가 올 수 있어요. 방치 시 사회적·브랜드 리스크. **차단이 아니라 돕는 방향**이 핵심.
- **구현**: 편지/답장/채팅에서 위기 키워드 감지 → **상담 안내 노출**(예: 자살예방상담 109 등). 발신자에겐 작성 시, 수신자에겐 표시 시. 금칙어 인프라 재활용 가능하나 "차단" 아닌 "안내"로 분기.
- **노력**: 소~중. **주의**: 오탐(맥락 없는 매칭) 주의, 가볍게 시작.

### 5. 차단 후 상호작용 완전 차단 점검
- **왜**: 차단은 편지뿐 아니라 **기존 채팅방·답장**까지 막혀야 안전.
- **구현**: 차단 후 기존 채팅방 접근/메시지 수신, 답장 가능 여부를 점검·보강(현재 send_bottle만 양방향 제외 확인됨).
- **노력**: 소.

## P2 — 운영 효율 (출시 후도 가능)

### 6. 신고 처리 SLA 자동화
- **현재**: 신고 메일 알림 + 수동 처리(runbook A안) + "24시간 이내 확인" 표기.
- **보강**: 동일 콘텐츠/유저 신고 N회 누적 시 **자동 임시 가림(숨김)** 트리거 → 24h 실질 대응 보장. 운영 모니터링 쿼리 정리(신고 다발·차단 다발 유저).
- **노력**: 소~중.
